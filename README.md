# Caltucalor – instalace z prohlížeče

Stránka `index.html` nahraje program do kalkulačky Caltucalor (ESP32-S3) přes USB přímo z Chrome / Edge
pomocí [ESP Web Tools](https://github.com/esphome/esp-web-tools) (Apache 2.0, ve složce `esp-web-tools`).

Programy jsou ve složce `firmware/<verze>/<deska>/` (každá má svůj `manifest.json`), displej ST7789.
